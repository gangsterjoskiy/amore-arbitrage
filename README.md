# A|More Arbitrage

Telegram-бот для мониторинга межбиржевых расхождений цен на спотовых USDT-парах. Первая версия использует публичные котировки Binance, Bybit, OKX, Kraken, Gate.io и KuCoin. Kraken используется как резервный источник, если Binance/Bybit недоступны. Автоматическая торговля и API-ключи бирж не используются.

## Возможности MVP

- Сравнение ask покупки и bid продажи на разных биржах.
- Расчётный спред после taker-комиссий обеих сторон.
- Фильтр по глубине лучшей цены.
- До 8 лучших результатов в Telegram.
- Команды /start, /scan, /subscribe, /unsubscribe, /help.
- Периодические сигналы через Cloudflare Cron и KV с защитой от повторов на 5 минут.
- Нет API-ключей бирж и функций размещения ордеров.

## Ограничения

Положительный расчётный спред не означает гарантированную прибыль. Первая версия не моделирует комиссии и сроки вывода, доступность сетей, проскальзывание, исполнение полного объёма, изменение цены между проверкой и сделкой, индивидуальные тарифы и региональные ограничения. Это мониторинг для бумажного тестирования, а не торговая рекомендация.

## Развёртывание на Cloudflare Workers

1. Создай KV namespace с именем SUBSCRIBERS в Cloudflare.
2. Скопируй его ID и замени REPLACE_WITH_KV_NAMESPACE_ID в wrangler.toml.
3. Разверни Worker из репозитория.
4. В настройках Worker добавь Secrets: TELEGRAM_BOT_TOKEN, TELEGRAM_WEBHOOK_SECRET и WEBHOOK_PATH_SECRET. Используй отдельные случайные строки для двух последних секретов.
5. Необязательные Variables (значения комиссий в процентах): BINANCE_TAKER_FEE, BYBIT_TAKER_FEE, OKX_TAKER_FEE (по умолчанию 0.1); MIN_NET_SPREAD_PERCENT (0.25); MIN_TOP_OF_BOOK_DEPTH_USDT (25). Значение 0.1 означает 0,1%. Укажи реальные тарифы своего аккаунта перед тестированием.
6. Установи webhook запросом к Telegram Bot API, подставив свои значения (токен не публикуй):

   curl -X POST "https://api.telegram.org/bot<TOKEN>/setWebhook" -d "url=https://<WORKER>.workers.dev/telegram/<WEBHOOK_PATH_SECRET>" -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>"

7. Отправь боту /start, затем /scan.

## Проверка

GET /health возвращает JSON с ok: true. Команда /scan получает публичные котировки в момент запроса. npm run check проверяет синтаксис JavaScript.


## Демо-балансы

- Команда /demo показывает два независимых виртуальных счёта: Арби и Трейдинг.
- Начальный баланс каждого счёта — 1 000 USDT.
- Команда /demo_reset или кнопка в меню сбрасывает оба счёта.
- Данные хранятся отдельно по Telegram chat ID в Cloudflare KV.
- /trade или кнопка «Трейдинг — сигнал» анализирует закрытые минутные свечи BTC, ETH, SOL, BNB и XRP по EMA 9/21, RSI и свечной динамике. При совпадении условий открывает одну виртуальную позицию на чат с экспирацией 60 секунд.
- Cloudflare Cron проверяет завершившиеся позиции; результат сравнивает направление с текущей публичной ценой Binance. Виртуальная выплата при выигрыше моделируется как 80% от ставки 10 USDT; при проигрыше теряется 10 USDT.
- /arbi_demo или кнопка «Арби — демо-сделка» записывает модельный P/L от лучшего найденного net-спреда для условного объёма 100 USDT. Это оценка по top-of-book, а не подтверждённое исполнение.
- /demo_reset сбрасывает оба виртуальных счёта. Данные хранятся в Cloudflare KV.
- Все значения виртуальные. Модели экспериментальные, точность не подтверждена; минутная цена и задержка cron могут влиять на расчёт результата. Реальные средства, брокерские ставки и биржевые ордера не используются.

## Telegram Mini App

- Главный экран переключается между режимами **A|MORE Arbitrage** и **A|MORE Signals**.
- Arbitrage показывает публичные котировки, доступность бирж, net-спред после комиссий и список возможностей с фильтром по паре.
- Рынок: свечной график Binance Spot с интервалами 1m, 5m, 15m, 30m, 1h и 4h.
- Signals: выбор BTC, ETH, SOL, BNB, XRP или всех пар; таймфреймы 1m, 5m, 15m, 30m или авто. Прогноз создаётся только при совпадении условий стратегии.
- Персональные демо-балансы, открытый прогноз и сброс счётов доступны в Mini App. API проверяет подпись Telegram WebApp initData перед доступом к пользовательским данным.
- STOP отключает новые виртуальные прогнозы и автоматические уведомления для конкретного Telegram-аккаунта. Уже открытый прогноз рассчитывается до экспирации. RESUME снимает блокировку.
- STOP не является кнопкой отмены реального ордера: размещение реальных ордеров в проекте отсутствует.

Все функции тестовые. Результаты стратегии не гарантированы и должны оцениваться на длинной выборке до любых решений о реальных деньгах.
